# MyCoach

Coach audio intelligent pour les entraînements de course à pied.

## Objectif du MVP

À partir d'une séance TrainingPeaks (JSONV2), générer automatiquement un MP3 synchronisé qui guide le coureur sans qu'il ait besoin de regarder sa montre.
